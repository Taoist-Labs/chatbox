## 一、软件介绍

### 1.1 软件定位

Wamo Chat 是一款运行在 Android 设备上的 AI 对话应用，支持多模型接入、移动端会话管理、图片理解、联网问答与图片生成等能力，面向移动办公与日常智能助手场景。

### 1.2 开发目的

本软件旨在将大模型能力沉淀为可直接在手机端使用的产品形态，让用户无需复杂部署即可完成问答、写作、资料整理和图像创作，提高移动场景下的信息处理效率。

### 1.3 主要功能概览

1. 模型提供方配置与模型切换。
2. 新建会话与多轮对话。
3. 文本文件上传与理解（移动端有文件类型限制）。
4. 图片上传与视觉问答。
5. 联网问答（Web Search）。
6. 图片生成器。
7. 聊天内容导出/分享。
8. 通用设置与文档解析设置。

### 1.4 运行环境（Android）

以下为建议写法，请按你的申请表内容替换：

- 设备环境：Android 手机（建议 4GB+ 内存）。
- 操作系统：Android 版本以申请表填写为准。
- 网络环境：可访问所配置模型服务地址。
- 安装方式：APK 安装。

### 1.5 版本功能边界说明

本说明书仅覆盖 Android 端可见功能。  
桌面端专有模块（如部分桌面工具能力）不作为本说明书主体内容。

### 1.6 主界面展示

主界面由“会话列表、消息区域、输入区域、底部功能按钮”组成，用户可在手机上完成对话、上传文件/图片和功能切换。

## 三、异常处理与注意事项（Android）

### 3.1 常见问题

1. 发送失败：多由网络不可达、API Host 错误或 Key 无效导致。
2. 模型不可用：模型 ID 配置错误、账户无权限或配额不足。
3. 文件处理失败：文件类型不支持或移动端本地解析能力受限。
4. 图片问答失败：当前模型未启用视觉能力。

### 3.2 处理建议

1. 优先检查网络状态与代理设置。
2. 在设置中核对提供方与模型参数。
3. 切换可用模型后再次测试。
4. 必要时导出日志用于定位问题。

### 3.3 合规注意事项

1. 软件名称、版本号必须与申请材料一致：`Wamo Chat V1.0`。
2. 截图内容应与 Android 运行环境一致。
3. 每个功能模块需独立描述，不得整段重复。
